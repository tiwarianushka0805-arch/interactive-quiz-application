# Interactive Quiz Application

An interactive quiz application built using HTML, CSS, and JavaScript as part of Lecture 10. It tests basic programming and software development knowledge through multiple-choice questions.

## Features

- Displays five multiple-choice questions.
- Allows users to select an answer for each question.
- Calculates the final score automatically.
- Displays the score after the quiz is completed.
- Uses a blue, white, and gold colour scheme.
- Provides a simple and user-friendly interface.

## Technologies Used

- **HTML:** Structures the quiz webpage.
- **CSS:** Styles the webpage and quiz options.
- **JavaScript:** Handles questions, answer checking, and score calculation.

## Project Files

- `index.html` — webpage structure.
- `style.css` — visual styling.
- `script.js` — quiz questions and functionality.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Select an answer for each question to complete the quiz.
4. View your final score.

## Learning Outcome

This project demonstrates the use of HTML, CSS, and JavaScript to build an interactive web application and handle basic user interactions.
